## The shared product contract

Think-wide helps people and agents navigate evidence across projects. It retains decisions and emits a scoped implementation brief. Specialist coding agents implement inside the target repository. Think-wide does not repair code, run target tests, install target dependencies, create branches/PRs, merge/deploy, or dispatch an autonomous coder. Trusted bounded Git/text/AST reads remain useful product tools.

Convex owns application state. Git evidence is identified by snapshot/blob/path/range and remains exact. The metadata tree is a navigable index, not another authored source tree. Generated views can change; human decisions and exact refs survive. One operation/policy boundary is shared by owned web, MCP, and any CLI.

The interface uses a reviewed tweakcn/shadcn theme, TanStack/React components and a closed semantic catalog. MCP remains a real agent-facing interface, not a future logo. A local demonstration does not prove remote ChatGPT/Claude.ai connectivity.
