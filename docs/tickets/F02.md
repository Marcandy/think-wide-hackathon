# F02 | Submission, disclosure, and Code Registry handoff

**Product invariant:** Think-wide supplies cross-project evidence/decisions/briefs. It does not repair or execute source projects. Trusted bounded read-only analysis remains allowed. Exact references and current authorization govern every surface.

**Evidence rule:** Documentation/fixtures, installed APIs, local real handlers, live provider/host, and deployment are separate statuses. No pass without an actual result at the identified commit/config.

## Issuance

Suggested specialty: **Eassa**. Actual owner: unclaimed until the PM assigns. Class: release.

Attempt timebox: **30 minutes**, including the first compatibility probe. Hard stop: **September 20, 2026, 17:30 EDT**, or earlier relevant feature cutoff. These bound effort; they are not promised completion times.

Prerequisite seed IDs: F01. Before READY, replace these with actual integrated commits/artifacts and record the contract version. No stale issue label is sufficient.

Writable areas: README, disclosure/technology/team list, demo and submission metadata. Confirm actual paths against the new checkout. Shared contract/lock/auth/infra changes need the designated owner and reviewer.

## Goal

Reconcile final artifacts and organizer requirements; prepare submission with the actual permitted repository, video and progress evidence.

## Done means

Human-reviewed submission package; prior work disclosed; source/dependency floor honestly checked if TCR; build stops at 17:30; actual sync/submission result recorded before deadline.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

Omit an ineligible optional prize claim; retain an honest valid selected-track submission if permitted. Never fabricate code count, timestamps, analysis results or eligibility.

## Review and handoff

Review partner: Marc + Andrew. Provide branch/commit, actual changed behavior, exact test commands/results, local/live/mock status, contract/config, remaining gaps, and next useful action. DONE requires acceptance and integration into trunk; otherwise REVIEW or BLOCKED.

Begin non-code submission preparation at 17:00. Sync must start before 18:00 for TCR. The packet is not authorization to submit or accept rules on behalf of teammates.
