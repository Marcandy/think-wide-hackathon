# T06 | Protected investigation and decision transactions

**Product invariant:** Think-wide supplies cross-project evidence/decisions/briefs. It does not repair or execute source projects. Trusted bounded read-only analysis remains allowed. Exact references and current authorization govern every surface.

**Evidence rule:** Documentation/fixtures, installed APIs, local real handlers, live provider/host, and deployment are separate statuses. No pass without an actual result at the identified commit/config.

## Issuance

Suggested specialty: **Eassa**. Actual owner: unclaimed until the PM assigns. Class: core.

Attempt timebox: **35 minutes**, including the first compatibility probe. Hard stop: **September 20, 2026, 13:30 EDT**, or earlier relevant feature cutoff. These bound effort; they are not promised completion times.

Prerequisite seed IDs: T02, T04. Before READY, replace these with actual integrated commits/artifacts and record the contract version. No stale issue label is sufficient.

Writable areas: core/authorization and commands, convex/investigations, decisions, runs, scoped query helpers. Confirm actual paths against the new checkout. Shared contract/lock/auth/infra changes need the designated owner and reviewer.

## Goal

Implement current object grants, persistent investigations/decisions, revision fencing, duplicate-command receipts, and admitted run state. This is the shared boundary Marc consumes.

## Done means

A/B own reads work and cross-owner operations fail in real handlers; correction persists; duplicate and changed-key cases behave correctly; jobs cannot publish under stale/revoked state.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

Hosted identity can remain a separate I01 integration. Keep isolated fixture-identity tests or loopback demo authority; do not expose test principals publicly or use admin credentials.

## Review and handoff

Review partner: Andrew. Provide branch/commit, actual changed behavior, exact test commands/results, local/live/mock status, contract/config, remaining gaps, and next useful action. DONE requires acceptance and integration into trunk; otherwise REVIEW or BLOCKED.
