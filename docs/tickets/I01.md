# I01 | Managed identity through the actual backend

**Product invariant:** Think-wide supplies cross-project evidence/decisions/briefs. It does not repair or execute source projects. Trusted bounded read-only analysis remains allowed. Exact references and current authorization govern every surface.

**Evidence rule:** Documentation/fixtures, installed APIs, local real handlers, live provider/host, and deployment are separate statuses. No pass without an actual result at the identified commit/config.

## Issuance

Suggested specialty: **Eassa**. Actual owner: unclaimed until the PM assigns. Class: integration.

Attempt timebox: **35 minutes**, including the first compatibility probe. Hard stop: **September 20, 2026, 14:30 EDT**, or earlier relevant feature cutoff. These bound effort; they are not promised completion times.

Prerequisite seed IDs: T06. Before READY, replace these with actual integrated commits/artifacts and record the contract version. No stale issue label is sufficient.

Writable areas: src/server/auth/, convex/auth.config and principal mapping, non-secret integration receipts. Confirm actual paths against the new checkout. Shared contract/lock/auth/infra changes need the designated owner and reviewer.

## Goal

Configure the authorized WorkOS environment, confirm accepted resource/audience and issuer/JWKS, and prove a real user identity at the protected Convex handler.

## Done means

Real login/accepted principal; wrong-profile/expired cases rejected; no global cross-user client; session/logout policy tested; configured values recorded without secrets.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

After its bounded attempt, remain loopback/stdio on permitted public/synthetic sources. Multiuser and remote-host claims stay disabled. No auth weakening or public fixture mode.

## Review and handoff

Review partner: Andrew. Provide branch/commit, actual changed behavior, exact test commands/results, local/live/mock status, contract/config, remaining gaps, and next useful action. DONE requires acceptance and integration into trunk; otherwise REVIEW or BLOCKED.

Start the metadata/export compatibility probe early during foundation. It must not block T03/T04/T05. Actual remote host login is completed in I04 after a safe endpoint exists.
