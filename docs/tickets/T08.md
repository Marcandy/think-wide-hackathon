Expose the same scope/browse/search/read/decision/handoff contract through MCP using the installed supported SDK profile. Keep exact-read and guidance tools even without embedded UI.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

Use a supported local stdio or loopback transport with the same domain rules. Mark remote ChatGPT/Claude.ai support incomplete; never publish an anonymous test endpoint.
