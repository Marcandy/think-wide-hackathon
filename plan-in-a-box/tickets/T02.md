**Product invariant:** Think-wide supplies cross-project evidence/decisions/briefs. It does not repair or execute source projects. Trusted bounded read-only analysis remains allowed. Exact references and current authorization govern every surface.

**Evidence rule:** Documentation/fixtures, installed APIs, local real handlers, live provider/host, and deployment are separate statuses. No pass without an actual result at the identified commit/config.

## Issuance

Suggested specialty: **Eassa**. Actual owner: unclaimed until the PM assigns. Class: core.

Attempt timebox: **45 minutes**, including the first compatibility probe. Hard stop: **September 20, 2026, 12:30 EDT**, or earlier relevant feature cutoff. These bound effort; they are not promised completion times.

Prerequisite seed IDs: T01. Before READY, replace these with actual integrated commits/artifacts and record the contract version. No stale issue label is sufficient.

Writable areas: contracts/, generated/, scripts/ build checks, convex/schema.ts and auth scaffold, infra/local configuration. Confirm actual paths against the new checkout. Shared contract/lock/auth/infra changes need the designated owner and reviewer.

## Goal

Author the first public contract during the event, generate public types/runtime validators, and prove a local self-hosted Convex write/read using disposable data.

## Done means

Committed real lockfile; repeatable generation; nested invalid payload rejected; local Convex alive with persistent volume; no deploy admin credential in app clients. Record exact installed packages and actual calls.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

Unready remote hosting leaves the critical path. Use the proven local backend. For generator incompatibility pin its supported compiler/API or reduce the supported schema subset; no runtime any-shaped bypass.

## Review and handoff

Review partner: Andrew. Provide branch/commit, actual changed behavior, exact test commands/results, local/live/mock status, contract/config, remaining gaps, and next useful action. DONE requires acceptance and integration into trunk; otherwise REVIEW or BLOCKED.

Only the required operations and explicit handler registry. Do not generate a universal MCP/CLI platform. Publish the schema/fixture interface before waiting for all integration checks.
