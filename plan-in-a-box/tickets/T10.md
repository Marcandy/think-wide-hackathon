# T10 | One live reasoning driver and a real correction

**Product invariant:** Think-wide supplies cross-project evidence/decisions/briefs. It does not repair or execute source projects. Trusted bounded read-only analysis remains allowed. Exact references and current authorization govern every surface.

**Evidence rule:** Documentation/fixtures, installed APIs, local real handlers, live provider/host, and deployment are separate statuses. No pass without an actual result at the identified commit/config.

## Issuance

Suggested specialty: **Marc**. Actual owner: unclaimed until the PM assigns. Class: core.

Attempt timebox: **35 minutes**, including the first compatibility probe. Hard stop: **September 20, 2026, 15:00 EDT**, or earlier relevant feature cutoff. These bound effort; they are not promised completion times.

Prerequisite seed IDs: T07, T09. Before READY, replace these with actual integrated commits/artifacts and record the contract version. No stale issue label is sufficient.

Writable areas: src/server/reasoning or convex/internalActions, proposal validation, catalog composition. Confirm actual paths against the new checkout. Shared contract/lock/auth/infra changes need the designated owner and reviewer.

## Goal

Connect one real model path, either a working MCP host or admitted backend provider. Use bounded evidence instead of full repos, and change the conclusion after a human correction.

## Done means

Actual reasoning/tool round trip; tentative claim tied to refs; correction changes accepted comparison/brief; stale proposal rejected; model/source/coverage and live/mock state recorded.

## Stop and fallback

Stop at the timebox or hard stop, or after about ten minutes of unsupported API guessing. Preserve the branch and explain the concrete blocker before changing tasks.

Use the other already available approved driver, not another new orchestration library. If no live model is available, label the limitation and do not close the complete-agentic-loop gate.

## Review and handoff

Review partner: Eassa + Andrew. Provide branch/commit, actual changed behavior, exact test commands/results, local/live/mock status, contract/config, remaining gaps, and next useful action. DONE requires acceptance and integration into trunk; otherwise REVIEW or BLOCKED.

Single driver per run. No hidden second layout model. T07 fallback may allow a literal-only degraded demo, but structural search remains an explicit missing capability.
